## 0. 一句话需求

客服在**在线会话工具栏**可对 ALS 订单**登记阿里赔付**；金额按「**预报下单日汇率**」把申报货值折成人民币再加运费；系统提供**赔付列表**（按日期/类型等过滤）并支持**按模板字段导出**。


---

## 1. 背景与目标

### 1.1 背景

跨境物流客服处理阿里侧丢件/破损等索赔时，需登记赔付信息。业务以 Excel 模板字段为准，金额必须按客户**预报下单当日汇率**折算为人民币，避免人工手算出错。

### 1.2 目标

1. 会话中快速登记赔付（输入 ALS → 自动带出订单信息 → 计算金额 → 保存）
2. 独立菜单管理全部赔付记录（筛选、详情、删除、导出）
3. 导出列与 `阿里赔付模版.xlsx` **表头一致**，便于运营汇总

### 1.3 非目标（本期不做）

## 2. 关键约束（必须遵守）

### 2.1 入口位置（极易做错，请严格按此实现）

**正确：在线会话 → 聊天输入区上方工具栏**

工具按钮顺序固定为：

```text
尾程单号 → 签收凭证POD → 物流轨迹与状态 → 尾程面单 → 订单日志→ 合单查询 → 添加赔付
```

即：「添加赔付」必须紧挨在「订单日志」**后面**，同一工具栏区域。

**错误（禁止）：**

- 放在右侧「快捷回复」Tab 内
- 放在「订单日志」弹窗内部作为主入口（可保留次要入口，但主入口必须在工具栏）
- 单独做成与工具栏无关的悬浮按钮

**另有菜单入口：**

- 左侧导航增加「阿里赔付」→ 列表页（路由建议 `/compensation`）
- 列表页右上角也可「添加赔付」（同一弹窗组件）

### 2.2 金额计算公式（必须）

```text
赔付货值金额(CNY) = round2( 申报货值(原币) × 下单日汇率 )
赔付运费金额(CNY) = round2( 运费(CNY) )
赔付总金额(CNY)   = round2( 赔付货值金额 + 赔付运费金额 )
```

- `round2` = 四舍五入保留 **2 位小数**
- 汇率必须取自 **客户预报下单时间（orderTime）所在日期** 的汇率，**不是登记日、不是当天实时汇率随意取**
- UI 必须以 **人民币 ¥** 展示货值、运费、合计
- 展示汇率说明示例：`1 USD = 7.12 CNY`

## 3. 数据模型

### 3.1 模板字段（导出 / 列表必须覆盖）

对齐 `阿里赔付模版.xlsx` 第 1 行表头：


| 字段中文 | 建议字段名 | 类型 | 说明 |
| --- | --- | --- | --- |
| 客户预报下单时间 | `orderTime` | datetime/string | 由 ALS 查单带回 |
| 登记时间 | `registerTime` | datetime/string | 保存时系统生成 |
| 客户单号 | `alsNo` | string | ALS…，必填 |
| 追踪单号 | `trackingNo` | string | 查单带回，可只读 |
| 转单号 | `transferNo` | string | 查单带回，可只读 |
| 责任方 | `responsibleParty` | enum/string | 下拉 |
| 赔付类型 | `compensationType` | enum | 见下表，**固定枚举** |
| 赔付原因 | `reason` | string | 必填 |
| 赔付货值金额（CNY） | `goodsAmountCny` | number(2) | 计算得出 |
| 赔付运费金额（CNY） | `freightAmountCny` | number(2) | 计算/可改运费后重算 |
| 赔付总金额（CNY） | `totalAmountCny` | number(2) | 计算得出 |
| 汇率 | `exchangeRate` | number | 下单日汇率 |
| 赔付工单号 | `ticketNo` | string | 系统生成，如 `PF20261106123` |

建议扩展（可不导出）：`id`、`declaredValue`（原币申报货值）、`currency`、`createdBy`、`sessionId`、`customerName`。

## 4. 功能说明

### 4.1 添加赔付（弹窗）

**触发：**

1. 在线会话工具栏「添加赔付」
2. 阿里赔付列表页「添加赔付」

**交互流程：**

```text
打开弹窗
  → ALS 输入框默认带入：最近查过的 ALS / 当前会话 orderNo（若有）
  → 用户点「查询订单」（或打开时已有 ALS 则自动查询）
  → 回填：预报下单时间、追踪单号、转单号、承运商、申报货值、运费、下单日汇率
  → 用户选择：赔付类型、责任方；填写：赔付原因
  → 允许微调：申报货值、运费（调后实时重算金额）
  → 展示计算结果：货值CNY / 运费CNY / 总金额CNY
  → 点「保存赔付」落库
  → Toast 成功；可选：把一段说明文案追加到会话回复输入框，方便告知客户
```

**校验：**

- ALS 必填且能查到订单，否则不可保存
- 赔付类型、责任方、赔付原因必填
- 申报货值、运费 ≥ 0

**查单失败：**

- 提示「未查询到该 ALS 订单」
- 不展示金额卡片 / 不允许保存

### 4.2 阿里赔付列表页

**路由：** `/compensation`（名称「阿里赔付」）

**左侧菜单：** 与工单管理同级，增加「阿里赔付」菜单项。

**页面能力：**

1. 统计区（可选）：全部条数、赔付总额(CNY)、部分类型计数
2. 筛选：
   - 关键词：ALS / 追踪号 / 转单号 / 工单号 / 原因 / 客户名
   - 赔付类型（含「全部」）
   - **登记日期**区间
3. 表格列：至少覆盖模板核心字段（登记时间、下单时间、ALS、追踪号、转单号、类型、责任方、汇率、货值、运费、总金额、工单号）
4. 操作：详情抽屉、删除（需确认）
5. 分页
6. 右上角：导出 + 添加赔付

排序建议：按 `registerTime` 倒序。

### 4.3 导出

- 导出对象：**当前筛选结果全集**（不是仅当前页）
- 无数据时禁止导出并提示
- 文件格式：CSV（UTF-8 **带 BOM**，Excel 可直接打开）或 xlsx；列顺序与模板表头一致
- 文件名示例：`阿里赔付_yyyyMMdd_HHmm.csv`
- 金额导出为两位小数字符串（如 `1328.48`）

## 5. 依赖数据（查 ALS 时后端需返回）

实现「查询订单」时，后端/OMS 至少返回：

```json
{
  "alsNo": "ALS02010204573",
  "orderTime": "2026-10-09 10:12:00",
  "trackingNo": "1Z999AA10123456784",
  "transferNo": "TRF-SZ-884210",
  "courier": "UPS",
  "currency": "USD",
  "declaredValue": 186.5,
  "freightCny": 89.0,
  "customerName": "禹逸飞"
}
```

另需汇率服务：

```text
GET /api/fx/rate?date=2026-10-09&from=USD&to=CNY
→ { "rate": 7.12 }
```

前端（或后端保存前）用该 rate 计算三项 CNY 金额。

> 建议：**金额最终以后端保存时重算为准**，前端展示可先算；防篡改。
